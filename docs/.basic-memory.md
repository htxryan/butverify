# Basic Memory

This repository participates in the shared Basic Memory project **`butverify`**, hosted at `../butverify-service/docs/`. Both `butverify` and `butverify-service` write notes into a single shared knowledge base.

- Project name: `butverify`
- Notes path: `../butverify-service/docs/` (canonical host: `butverify-service` repo)

Basic Memory is configured globally as an MCP server for Claude Code (`basic-memory`) and Codex CLI (`mcp_servers.basic-memory`). When working in this repo, point agents at the `butverify` Basic Memory project regardless of which repo they're in.

See https://docs.basicmemory.com/how-to/project-documentation for project documentation patterns.
